# Rekisi Map Note

**Write Japanese history on your own map**

> Currently in development. The release date will be announced on this page.

---

## What is Rekisi Map Note?

A notebook app for learning Japanese history by organizing events by era and place. Use it to relearn the basics or to dig deeper.

- Move through the eras with the **era slider**
- Write the events you looked up onto the **map of Japan**
- Review them with **quizzes** generated from your own notes

Look it up, write it down, and place it on the map. Notes you write yourself stay in your memory.

---

## Planned Features

| Feature | Description |
|-----|------|
| Era slider | Switch the map by era, from the Jōmon period to Reiwa |
| Notes on the map | Long-press the map to add an event, tap a marker to see the details |
| Historical place names | Shows a place as, for example, "Musashi Province (today's Tokyo and Saitama)" |
| Sample events | Includes the events that mark the start of each era. You can edit or delete them freely |
| Quizzes | Location, era, and ordering quizzes generated from your own notes |

### What You Can Record

| Field | Description |
|-----|------|
| Title | e.g. Battle of Sekigahara |
| Date | A year, a range of years, or just an era |
| Place | A position on the map (optional) |
| Memo | Free text |
| Source | A URL, a book page, etc. |
| Tags | People, battles, culture, etc. |

Rekisi Map Note is a **notebook you write yourself**. Apart from the sample events, it does not include descriptions of historical events.

## Your Data Stays with You
